# Contributing to SecureChat

## Code of Conduct
We are committed to providing a welcoming and inspiring community for all.

## How to Contribute

### Reporting Bugs
1. Check if bug already exists
2. Include clear description and steps to reproduce
3. Provide environment details (OS, Node version, etc.)
4. Include error messages and logs

### Feature Requests
1. Describe the feature and expected behavior
2. Explain why it would be useful
3. Provide examples if applicable
4. Consider implementation approach

### Pull Requests
1. Fork the repository
2. Create feature branch: `git checkout -b feature/feature-name`
3. Make your changes
4. Write or update tests
5. Commit with clear messages
6. Push to your fork
7. Create Pull Request with description

## Development Setup
See [DEVELOPMENT.md](DEVELOPMENT.md)

## Code Standards
- Use TypeScript
- Follow existing code style
- Write tests for new features
- Add JSDoc comments for public APIs
- Update documentation

## Testing
- Write unit tests for new features
- Ensure all tests pass: `npm test`
- Aim for 80%+ code coverage

## Commit Messages
- Use present tense: "Add feature"
- Be descriptive and concise
- Reference issues: "Fixes #123"
- Example: `Add JWT token refresh endpoint - Fixes #456`

## Documentation
- Update README for new features
- Add API documentation for endpoints
- Include code examples
- Update CHANGELOG

## Community
- Be respectful and inclusive
- Help others with questions
- Share knowledge and insights
- Report security issues privately

## Questions?
- Check existing documentation
- Search closed issues
- Ask in discussions
- Contact maintainers

Thank you for contributing to SecureChat! 🎉
